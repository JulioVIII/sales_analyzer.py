
# Python Sales Analyzer

A Python project that analyzes sales data using Pandas.

## Features

- Loads sales data from a CSV file.
- Calculates total revenue and average order value.
- Groups revenue by product and city.
- Identifies the top product by revenue.
- Filters high-value orders.
- Sorts orders by revenue.
- Counts orders by city.

## Technologies

- Python
- Pandas
- CSV

## How to Run

1. Install Python.
2. Install Pandas using `pip install pandas`.
3. Place both files in the same folder.
4. Run the program:

   `python sales_analyzer.py`
